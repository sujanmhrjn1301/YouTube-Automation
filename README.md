# 🎬 YouTube Shorts Automation Pipeline

A production-grade, modular Python application that automates the extraction, reframing, subtitling, and uploading of viral segments from long-form YouTube videos into high-retention YouTube Shorts.

---

## ⚡ Pipeline Architecture

```
[ Long-form YouTube Video ]
            │
            ▼
┌─────────────────────────┐
│ 1. Ingestion (yt-dlp)   │ ──► Best MP4 video (up to 1080p) + 16kHz mono WAV extraction
└───────────┬─────────────┘
            ▼
┌─────────────────────────┐
│ 2. Word Transcription   │ ──► faster-whisper CTranslate2 (Segments + Word Timestamps)
└───────────┬─────────────┘
            ▼
┌─────────────────────────┐
│ 3. Viral Moment AI      │ ──► LLM Analysis (OpenAI / Gemini / OpenRouter)
│    (30 - 55 seconds)    │     Hook score, standalone coherence, title, description, tags
└───────────┬─────────────┘
            ▼
┌─────────────────────────┐
│ 4. 9:16 Video Reframing │ ──► Blurred Background / Face Tracking (YuNet) / Center Crop
└───────────┬─────────────┘
            ▼
┌─────────────────────────┐
│ 5. Dynamic Karaoke Subs │ ──► Animated ASS subtitles with synchronized word-level pop
└───────────┬─────────────┘
            ▼
┌─────────────────────────┐
│ 6. YouTube Data API v3  │ ──► Resumable OAuth upload with chunked terminal tracking
└───────────┬─────────────┘
            ▼
┌─────────────────────────┐
│ 7. Supabase Sync        │ ──► Video upload to Storage bucket & metadata row insertion
└─────────────────────────┘
```

## 🚀 Quickstart & Usage

### 1. Run System Health Check
```bash
python cli.py --doctor
```

### 2. View Available CLI Options
```bash
python cli.py --help
```

### 2. Generate a YouTube Short (Uses OpenRouter by default)
```bash
python cli.py --url "https://www.youtube.com/watch?v=VIDEO_ID" --crop-mode blurred_background
```

### 3. Generate with Specific OpenRouter Model or Face Tracking
```bash
python cli.py --url "https://www.youtube.com/watch?v=VIDEO_ID" --crop-mode face_tracking --llm-model "openai/gpt-4o-mini"
```

### 4. Generate and Auto-Publish to YouTube
```bash
python cli.py --url "https://www.youtube.com/watch?v=VIDEO_ID" --auto-upload
```

## ⚙️ Configuration Reference

Options passed via CLI:
- `--url`: YouTube source video URL (**required**).
- `--model-size`: Whisper transcription model (`tiny`, `base`, `small`, `medium`, `large-v3`, default: `base`).
- `--llm-provider`: Provider for viral moment detection (`openrouter`, `openai`, or `gemini`, default: `openrouter`).
- `--llm-model`: Model name (default: `openai/gpt-4o-mini`, or any OpenRouter model e.g. `meta-llama/llama-3.3-70b-instruct`).
- `--crop-mode`: Reframing strategy (`blurred_background`, `face_tracking`, `center_crop`, default: `blurred_background`).
- `--cookies-from-browser`: (Optional) Browser to import YouTube session cookies from (`chrome`, `firefox`, `edge`, `brave`) if YouTube enforces bot checks.
- `--auto-upload`: Flag to immediately trigger YouTube OAuth upload or save locally for review.

## 🗄️ Supabase Database Schema (Optional for Cloud Sync)

To enable pipeline run persistence in Supabase, execute this in your **Supabase SQL Editor**:

```sql
create table if not exists public.shorts_metadata (
    id bigint generated by default as identity primary key,
    source_url text not null,
    source_video_id text,
    source_title text,
    hook_title text,
    description text,
    tags text[],
    viral_reasoning text,
    hook_score integer,
    start_time numeric,
    end_time numeric,
    duration numeric,
    storage_url text,
    youtube_id text,
    created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
```
